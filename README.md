This package allows quizmasters to run their own quiz night.
The start page can be used for intros, rules, whatever you need to remember before the quiz starts.
<img width="485" height="849" alt="image" src="https://github.com/user-attachments/assets/1cb0d41e-84ca-4c2e-896b-e033cf0d81c5" />
The Teams columns on the start page allows you to enter team names with number of members per team. It also allows you too track the total prize fund (if you're operating that way).
The team names and handicaps will be passed to the scoreboard and leaderboard
